# Phase 1 Setup Note

Phase 1 has prepared the initial project assets.

To use this project:

1. Upload or unzip this folder into Google Drive or your local machine.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Check the documents in:

```text
data/documents/
```

4. Check the evaluation questions in:

```text
data/evaluation/evaluation_questions.csv
```

Phase 2 will implement document loading, chunking, vector retrieval, and the basic RAG pipeline.
